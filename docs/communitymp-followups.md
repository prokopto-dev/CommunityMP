This file tracks compatibility work that is known to remain after the current OpenMW/TES3MP compatibility pass. Keep this list focused on features that are likely to need real code changes or runtime validation.

- Current upstream-sync planning, recent decisions, risk notes, and release gates are tracked in `docs/communitymp-upstream-sync-roadmap.md`. Keep that document updated when backporting OpenMW milestone or work-item fixes that affect CommunityMP client, server, editor, scripting, physics, rendering, or packaging behavior.

## GameNetworkingSockets transport

- Replace the transitional RakNet-facing packet surface with explicit TES3MP packet address, connection, and datagram types.
- Keep packet serialization TES3MP-owned. `PacketStream` now uses a local bit/byte stream implementation instead of `RakNet::BitStream`; remaining cleanup should focus on reducing the temporary `PacketStream` API itself once packet parity coverage is broad enough.
- Keep master announcement endpoint serialization GNS-native. The advertised gameplay port is now unconditional in `PacketMasterAnnounce` because GNS is mandatory, and the master/browser guard rejects restoring a conditional GNS/RakNet branch for that field.
- Keep TES3MP target wiring tied to `BUILD_TES3MP_TARGETS` instead of any local GNS transport switch. Components, OpenMW client, TES3MP server, and GNS transport tests now add/link GNS through mandatory TES3MP target wiring; the old `TES3MP_USE_GNS` compatibility option is removed from CMake, CI, and sync automation.
- Keep packet sends transport-only while the packet serialization surface is still transitional. `BasePacket` no longer stores a RakPeer pointer or falls back to `peer->Send`; send/request paths require the installed `PacketTransport`, and component coverage verifies packet send dispatch with a null RakPeer.
- Keep dedicated server startup and master publishing free of RakPeer ownership. `tes3mp-server` now constructs only the GNS server transport, passes `PacketTransport` into server networking, and initializes master announce packets without a RakPeer instance.
- Keep packet construction free of RakPeer plumbing. Packet controllers and packet classes now default-construct without RakPeer pointers; packet/address/serialization internals are routed through TES3MP-owned equivalents while the remaining cleanup focuses on retiring temporary compatibility-shaped APIs rather than CrabNet-backed types.
- Keep packet string serialization TES3MP-owned while the broader packet stream is still transitional. `BasePacket` string and RefId paths now use explicit length-prefixed byte serialization instead of `RakNet::RakString`; component coverage pins max-length clamping for both legacy compressed-flag and uncompressed call sites.
- Keep packet delivery priority/reliability and packet stream APIs TES3MP-owned while the transport surface is still transitional. `PacketDelivery.hpp` now defines the priority and reliability contract used by packet sends and GNS flag mapping instead of depending on RakNet's `PacketPriority.h`; `PacketStream.hpp` owns the temporary stream wrapper used by `BasePacket`, packet/master class `Packet`/`PacketHeader` methods, packet-controller stream APIs, runtime OpenMW/TES3MP networking, master/browser query paths, dedicated server utility stream usage, and packet/GNS component test stream construction without including or naming `RakNet::BitStream`; stream payload access now uses `data()` and `size()` instead of RakNet-shaped accessors; `PacketStream.cpp` now owns the legacy-compatible bit layout directly instead of delegating to CrabNet, and component coverage pins unaligned raw byte, compressed integer/float/double, byte-count, failed-read, reset/reuse, empty input, zero-length no-op, and zero-byte unaligned read semantics for that local implementation.
- Keep packet destinations TES3MP-owned at the transport boundary. `PacketIdentity.hpp` now owns the project `PacketAddress`, `PacketGuid`, and `PacketNetworkId` value types, GUID size/construction/value/string formatting, packet-header GUID read/write helpers, address construction/formatting/serialization/numeric-host validation/port/rewrite, and unassigned/assigned helpers, `PacketDestination.hpp` stores explicit GUID/address fields, exposes assigned-state helpers for GNS routing, and keeps `BasePacket`, `PacketTransport`, GNS public send/close/ping methods, runtime invalid-player checks, runtime GUID logging/skip/default helpers, dedicated-server player/networking/cell identity APIs, OpenMW client player/dedicated-player/ally/cell/marker identity APIs, OpenMW client networking processor identity/address state, dedicated-server admin ping helpers, Lua `GetIP`, server runtime address logging, master publisher endpoint storage, master/browser query/update endpoint APIs, standalone master server storage, REST lookup/listing, browser list formatting, optional master test utility endpoints, base gameplay/player/actor/object/worldstate identity models, the server script ABI network-id encoder, and packet/GNS component test identity construction from exposing RakNet's `AddressOrGUID` wrapper, direct address APIs, raw address formatting, or unassigned address sentinels directly. Component coverage now pins `PacketAddress` IPv6 formatting, hostname port rewrites, serialization, oversized host rejection, and truncated-read behavior. The internal connection-address lookup is now named `getPacketAddress` instead of carrying RakNet's `SystemAddress` term through active C++ transport APIs.
- Keep received packet ownership and routing metadata TES3MP-owned at the transport boundary while packet processors parse transitional streams through `PacketStream`. `ReceivedPacket.hpp` now owns byte storage plus `PacketGuid`/`PacketAddress` metadata directly, exposes ID/data/length/GUID/address/destination accessors without a `RakNet::Packet` bridge, `PacketId.hpp` owns the transport-facing packet-id alias plus the legacy-compatible connection-status and user-packet boundary constants, packet controller dispatch now uses `PacketId` instead of `RakNet::MessageID`, `NetworkMessages.hpp`, `MasterData.hpp`, and browser direct ping no longer include RakNet's `MessageIdentifiers.h`, `GnsTransport.cpp` reads embedded packet GUID bytes without `RakNet::BitStream` and queues system packets without `RakNet::MessageID`, `PacketTransport::receive()` returns `ReceivedPacket*`, and the master publisher plus OpenMW client and dedicated server packet processors consume the wrapper directly.
